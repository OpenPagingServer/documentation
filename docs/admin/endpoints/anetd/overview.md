# Using Advanced Network Devices on Open Paging Server

Advanced Network Devices IP speakers, clocks, and displays can be configured as endpoints in Open Paging Server using Multicast RTP and HTTP requests. There is no official module, functionality, or support. So each device must be configured manually.
