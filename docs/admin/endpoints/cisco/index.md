Cisco IP Phones can be integrated with Open Paging Server using the Cisco IP Phones module. The phone can receive pages, both audible and visual messages, and bells. 

The module can be connected to CUCM to automatically import/sync phones.

The module can also be used to trigger messages upon outgoing calls from CUCM using External Call Control Profiles. This can be used for E911 alerts.

Audio is sent via Multicast or Unicast RTP. Visual messages use CGI execute.
