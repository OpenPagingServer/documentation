# Captcha

You can enable captcha on the login page for local login. You can use a basic text-based captcha, [Cloudflare Turnstile](https://www.cloudflare.com/products/turnstile/), or [Google reCAPTCHA](https://developers.google.com/recaptcha). Turnstile and reCAPTCHA require that you access Open Paging Server by a hostname approved in the respective service's administration panel.
