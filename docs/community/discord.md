# Discord

We have a public Discord server for community support, discussing development, support tickets, and for hobbyists. The server is governed by a simple set of rules which is enforced by moderators. 

[Join our Discord server](https://discord.openpagingserver.org)

## Rules

1. Users must follow Discord TOS and be at least 13 years of age.
2. Any kind of drama or politics will not tolerated here. **__Anyone who breaks this rule is subject to immediately being permanently banned from this server without warning.__**
3. Distribution of cracked or otherwise non-public closed source software or code is not allowed here.
4. Leaking or sharing personal information is not allowed.
5. No discrimination.
6. No harassment/bullying. 
7. No "AI Slop" image/videos/text.

## Support

The Discord server has a ticket system for the purpose contacting project staff or server moderators.  **We DO NOT** provide support for our software outside of community support channels<!--, and our paid commercial support service-->. 

Community support is available in the Discord server. If you have any questions, need assistance, or encounter any issues, you can open a thread in the community-support forum channel and another member of the community will assist you.

For moderation inquires, open a ticket in the server or email discordstaff@openpagingserver.org
