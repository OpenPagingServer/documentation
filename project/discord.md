# Open Paging Server Discord

Our official Discord server is the primary channel for the community to discuss development and for community support. As well as a discussion board for hobbyists. 

[Join our Discord](https://discord.openpagingserver.org)
## Rules

The server is governed by a simple set of rules, enforced by server staff. **In order to participate in this server, you must agree and abide by the following rules:**

1. Users must follow Discord TOS and be at least 13 years of age.
2. Any kind of drama or politics will not tolerated here. **Anyone who breaks this rule is subject to immediately being permanently banned from this server without warning.**
3. Distribution of cracked or otherwise non-public closed source software or code is not allowed here.
4. Leaking or sharing personal information is not allowed.
5. No discrimination.
6. No harassment/bullying.
7. No "AI Slop" image/videos/text.
   
## Contact Server Staff

If you are in the server, you can contact the Open Paging Server staff, including server staff using a support ticket. Use the `#open-ticket` channel. 

If you are not in the server, you can contact Discord staff by emailing discordstaff@openpagingserver.org. (Use contact@openpagingserver.org to contact non-Discord staff)

Valid reasons for contacting server staff include, but is not limited to:

- Moderation concerns
  
- Requesting a review if you believe you were unfairly banned
  
- Requesting your messages be deleted if your account is deleted, you left the server, or you got banned
  
The ticketing system or email contact is **NOT** for support. Please use community support channels.
