# Supported Web Browsers

| BROWSER                         | MINIUM VERSION | RELEASED      |
| ------------------------------- | -------------- | ------------- |
| Google Chrome                   | 87 (Nov 2020)  | November 2020 |
| Microsoft Edge                  | 87 (Nov 2020)  | November 2020 |
| Mozilla Firefox                 | 66             | March 2019    |
| Apple Safari on Mac             | 14.1           | April 2021    |
| Apple Safari on iPhone and iPad | 14.5           | April 2021    |
In order for a web browser to be supported, it must support web development and security standards. Legacy browsers, normally found on older operating systems are not made for today's standards for computer applications and cybersecurity requirements. 

If you are using a legacy browser not supported, you may need to update your internet browser, operating system software, or device. If your device is owned by your organization, contact your IT or system administrator for help.

[Update Google Chrome or Microsoft Edge on a computer](chrome://settings/help)

[Learn how to update an iPhone or iPad](https://support.apple.com/en-us/118575)

[Update Chrome on an Android device](https://play.google.com/store/apps/details?id=com.android.chrome)
